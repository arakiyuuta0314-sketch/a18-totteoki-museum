# A18 エントランス 正面木製額縁の共通素材化・右手前変形 v04
2026-10-26｜美術完成候補・ユーザー最終承認待ち

## 制作方針
基準は正式な546×483エントランス。既存43・44・45は上書きしない。
44番の背面左「frame_left_wood_grain_v02.png」（正面の独立木製額縁）を**唯一の正面木製素材**として、右手前に射影変換で当て込んだ。

## 今回の改修
前回の v03 は右手前専用の大きな木製色面のαマスクを削っていたので、金縁位置と写真窓の右上・左下に隙間が出た。
今回、左右・上下を個別に移動するのでなく「元の正面素材の上・右・下・左の４辺」をそれぞれ射影変換。
写真窓は43番の承認済み透過マスクからOpenCVで四隅を実抽出。外側の四隅は元の金額縁の可視外周を基準に固定。
厚さが異なる二つの額縁でも、**外周と内窓の両方**を合わせるには、一枚の射影変換だけでは足りないため、4辺を同じ共通データで変換する。
将来の逆角度も同じ正面PNGと入出力の四隅ペアを別座標に変更すれば作れる。QA_reverse_angle_same_source_example.png は向きを反転した変形の技術例であり、美術館左側の完成候補ではない。
