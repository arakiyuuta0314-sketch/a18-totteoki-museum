# A18「とっておき美術館」右手前展示枠 v06（正面素材の単一射影変換）
2026-10-26｜最終美術承認待ち・ゲーム統合前

## v05の不整合と根本修正
v05では正面額縁の外周と写真窓に対して別々の目標四隅を入力していた。
一枚の平面にその四隅を適用すると最大約6.74pxずれるため、上下左右を4枚の別射影変換で継ぎ合わせていた。
それでは枠・台紙・写真のパースが必ずしも物理的に整合しない。
v06は次の方式へ変更。
1. 正面素材外周（左額縁元素材 76,50 / 200,50 / 200,156 / 76,156）を基準とする。
2. 右手前の元の金額縁の外形4点（419,187 / 499,212 / 499,338 / 417,292）へ一つのホモグラフィ H を計算する。
3. 右手前の写真窓4点は、正面写真窓へ **同じ H をかけて導出** する。別の入力値を使用しない。
4. 木枠・金枠・金枠本体・金装飾・空き台紙・写真サンプル・任意のユーザー写真テストを **同じ H のみで処理** する。
5. 写真窓マスクは正面マスクを同じ H で射影して生成。旧43/v05右手前マスクは再利用しない。写真窓のαは全状態で同じ。
6. 逆角度のテストは目的の外周4点だけを変更し、同じ frame_projection_v06.py を再利用。
