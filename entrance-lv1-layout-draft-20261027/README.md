# A18 Lv.1 エントランス｜既存背景を使った配置確認（未採用ドラフト）

2026-10-27時点で相談し、ユーザーが確定した**役割・枚数・向き**を配置モックにする。画像中の設備形状、寸法、角度、通路幅、爺や位置はすべて未承認の仮配置。

## 固定する要件
- エントランス展示は**合計3枚**。奥の既存2枚は位置・表示・中央扉とも変更しない。
- 左手前に**奥行き方向の横向きカウンター**。受付面は右（中央通路）向き、爺やは内側。
- 右手前に**額縁③を内蔵した仕切り壁**。フレーム③のゲームデータ自体は現在存在するが、現行公開ゲームでは奥の2枠のみ可視。
- 奥側の左右に通路を確保し、左右のエリアへ回り込める動線を作る。
- 背景を全面生成し直さない。カウンターと仕切り壁の前後レイヤーが必要なので、設備素材は将来分離する。
