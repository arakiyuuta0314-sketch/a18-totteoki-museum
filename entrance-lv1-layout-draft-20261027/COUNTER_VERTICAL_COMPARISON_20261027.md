# Lv.1：A案の受付を縦向きにした比較（未承認）

ユーザーの希望「A案の右仕切り壁は正面のまま、左カウンターを縦にしたらどうか」を、実際に公開ゲームで使用している承認済み背景への図形重ねで比較した。

- 真横カウンター＋右壁正面：`lv1_horizontal_counter_front_wall.jpg`（従来A案）。
- **縦カウンター＋右壁正面**：`lv1_vertical_counter_front_wall.png` / `.jpg`（比較C案）。
- 横並び：`lv1_counter_orientation_comparison.jpg`。
- 既存の奥2枚、中央扉、右の正面向き額縁③、中央通路の構想は維持。
- 左の縦カウンターは壁から離れた左側に置き、右側が受付面、爺やは左内側という仮定。実際の爺や座標は変えていない。
- 縦向き案は横幅を節約でき、中央は広くなる。一方、奥側の左通路や爺やの背面動線を狭める可能性があり、実機・当たり判定の確認前に採用と判断しない。
- 完成美術素材は未制作。写真データ・セーブ・レベル設定・ゲーム本体・公開版は無変更。比較図だけ作業ブランチに保存する。
