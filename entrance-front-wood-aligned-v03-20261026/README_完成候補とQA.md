# A18 右手前木製額縁 位置合わせ v03｜完成候補・美術確認待ち
2026-10-26

## 修正の理由
44番の右手前木製額縁は、金額縁の透明PNGとAlpha分離領域そのものは一致していた。
しかし43番の元金額縁のうち金色の見える細い縁取りは、その透過領域の一部分に限られる。
44番は透過領域全体を木色で塗っていたため、位置・角度・太さが金額縁からずれて見えた。
単なる座標移動ではなく、金額縁の実際の見える輪郭を原画から確認して木製版の表示範囲を修正。

## 変更した部分
- 右手前の木製透過素材1枚（frame_front_wood_grain_aligned_v03.png）の表示マスクのみを加工。
- 左右背面の木製額縁、正式キャラクター、写真、壁、床、手すり、受付などは既存43/44番を使用、変更しない。
- 金額縁の視覚的な輪郭に基づいて外側四隅を固定: (420,191), (496,215), (497,334), (419,288)。
- 写真窓の内側は43番の正式 exhibition_front_window_mask.png をそのまま切り抜き、写真の位置・歪みを保つ。
- 素材は546x483の全キャンバス透過PNG。3状態のどれも同じ展示箇所の基準位置を使用する。
- 金額縁は独特の金装飾を持つため、木製と金属の視覚シルエットが「一画素完全一致」するわけではない。金装飾の画素改変もない。

## QA
- 金額縁本体の外側の表示位置を原画拡大画像で確認し、木製版の輪郭を合わせ直した。
- 金色の視覚マスクのうち約91.6%を、修正後の木製版の共通外形内に含む（残りは主に装飾の突出部等。色分割による定義であり厳密な輪郭一致率ではない）。
- 右手前旧マスクは5079画素。新木製マスクは3406画素（透明な周囲まで茶色く塗らない）。
- 右手前旧フレーム透過領域の外側で差分画素0。3段階の倍率（90/100/110%）と、空き台紙／写真の双方で他領域不変を検証。
- 額縁なし／旧木製／修正後木製／金額縁、写真2状態、3サイズ合計24実画像。
- Windows Chrome 390×844 CSS px / DPR2、24状態のボタン操作・写真読込・水平スクロールなし・JS/HTTPエラー0。
- 背面2額縁は4状態で常に木製のまま固定。右手前のみ切替。
- 建築照明・壁灯は未分離のまま。全画面の最終美術監修とゲーム統合は未実施。
