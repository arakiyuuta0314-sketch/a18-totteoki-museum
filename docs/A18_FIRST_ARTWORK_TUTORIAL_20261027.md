## 新しい初回の流れ
1. セピア導入で名前・男女、カラー館内の執事との会話で美術館名まで**既存のCAS保存**で確定。
2. カラーのエントランスを**自分で歩き**、執事の近くの「話しかける」で案内を開始。
3. 「最初の作品を預ける」から**既存の写真登録UI**を使用。画像データ原本、作品名、任意の備考等を登録し、作品を受け取る。
4. 作品を保持して**奥の額縁へ歩き**、「ここに飾る」で実際に展示する。
5. 執事は「最初の一枚が飾られましたな」と感嘆。特定の画像内容を推定しない。
6. 「そういえば……」で木製フレームを贈呈。プレイヤーが「木製フレームを受け取る」を選んだ時点で、**既存 `intro-v1` イベントを `seen` に原子保存**する。
7. 展示写真に、既存の額縁レンダラーの**木製・真鍮調の縁取りが実際に表示**され、「館内を見て回る」で終了。これ以降の執事は通常会話へ戻る。

## 保存・中断・互換性
- 新しい保存スキーマ・仮の画像・自動生成の写真・ダミー画像の補完は作らない。
- **写真登録確定時**に写真原本と `carrying` を既存のCASトランザクションで保存する。写真選択キャンセル時は作品未登録のまま。
- **額縁への展示確定時**に `fixtureId` を原子的に保存する。**フレーム贈呈とは別の確定境界**。登録・配置後に再起動しても保存済みの写真を保持する。
- **木製フレーム贈呈の確定境界**は `intro-v1` の `seen`。受領前に落ちたり閉じたりした場合、次に執事へ話しかけた際、贈呈を再開する。二重贈呈しない。
- フレームの見た目は**既存の入口2つの後壁展示枠**のみ、初回 `intro-v1=queued` の間だけ縁取りを一時的に抑え、`seen` で表示する。**新しい木製画像素材を制作したわけではない**。このチュートリアルで既存の28設備レコード、内部の `fixture.design` や他室のLv.別装飾は変更しない。
- 古いセーブで既に `intro-v1=seen/available` の場合、写真が飾られていれば従来の額縁を表示し、勝手に初回イベントをやり直さない。
- 保管した作品は執事の案内から作品一覧で再度取り出せる。
- `intro-v1` が保留中の間、進行に合う案内を画面に表示し、受領完了後は消す。
- 保存失敗は既存の fail-fast 動作に従い停止し、自動の縮退・勝手なイベント完了はしない。
