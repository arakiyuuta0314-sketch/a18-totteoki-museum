# A18 チュートリアル画面・会話・登録項目の調整（2026-10-27）

## ユーザー監修で決まった変更
- 初回の館名設定は「見出し＋長文＋フォーム一括」ではなく、執事との**通常の会話を一つずつ**進め、最後に美術館名を設定する。話者名・顔・本文の表示スタイルは他のゲーム内会話と統一。途中で入力欄を表示しない。
- 上部の「館長を歩かせて、額縁に近づこう」は不要。新しいチュートリアル案内は**館内表示の下端付近、操作UIの直上**へ表示する。作品の持ち運び・展示案内も同じ配置に統一する。
- セリフは日本語の句読点の行頭分離を抑える。名前と「様／お嬢様」を途中で分離しないよう、会話内の敬称部分は一単位として扱う。初回の館名設定では必要な箇所を改行している。
- 今後の作品登録は、**作品名・写真・備考／思い出（任意）**に絞る。**完成日・ピース数は登録フォーム、作品一覧、展示の詳細、鑑賞ビューアから削除**。
- ユーザーは既存作品データを削除済みと明言しているため、移行や旧作品の表示互換を要求しない。ただしv3の原子保存契約を不必要に壊さないよう、保存に必要な内部キー `complete`・`pieces` は新規登録時 `null` として残す。これらの項目を入力・閲覧するUIは今後使用しない。

- `layout-test/tutorial-ui-polish.css`：会話本文の折り返し、館名入力のサイズ、チュートリアルの通知位置。

- `layout-test/viewer.js`：鑑賞画面で旧項目の代わりに登録日と備考・思い出を表示。
- `layout-test/registration-compact.css`：廃止した日付入力用スタイルを削除。
- `docs/qa/test_opening_v1.py`、`docs/qa/test_opening_framed_transitions.py`：新しい会話3段階への移行を検証。
- `docs/qa/test_first_artwork_tutorial.py`：名前入力画面や下端通知、旧フィールド非表示、写真登録・原本保存、一覧とビューアの旧項目非表示、フレーム贈呈と再起動を検証。
