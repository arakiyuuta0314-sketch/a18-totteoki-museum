# A18 写真の四隅・撮影角度補正 Web公開（2026-10-27）

## 範囲
- 撮影角度が斜めになっているパズル写真で、矩形トリミングでは残る台形の歪みや外側の白い余白を補正する。
- 写真の四隅を手動で調整し、遠近補正（射影ホモグラフィ＋双線形補間）で長方形に変換する。
- 登録時の共通写真編集と、展示中に作品を調べる再編集の両方で同じ操作を利用。
- 原本Blobを変えず、従来の編集レシピと互換のまま、任意の四隅情報だけ保存する。
- 写真の中央にある光の反射を創作的に除去する機能は今回対象外。表示/出力最大辺4096px、画像の拡大超解像なし。
