# A18｜セピアオープニング・名前入力枠のコンパクト化（2026-10-27）

## 変更の背景
- iPhoneの実機スクリーンショットで、名前入力のダイアログが広がりすぎてセピアの絵にかかっていた。
- 画面下の黒帯の中に名前入力ダイアログを収める。
- 風景4枚・光・セリフ内容・名前保存方式・中間転換・最終の明転を変更しない。

## 修正
- `layout-test/opening-v1.js`：名前入力時のみ `a18-opening-name-entry` クラスを付与し、通常の会話に戻ったら外す。
- `layout-test/opening-v1.css`：該当時だけ余白・文間・入力欄・ボタンのサイズを縮小。iPhoneの入力時拡大を避けるため input 文字サイズは16pxを維持。
- `layout-test/index.html`：CSS・JSのキャッシュ更新。
- `docs/qa/test_opening_framed_transitions.py`：390×844と320×700の画面で、名前入力枠の高さおよび映像下端との非重複を追加検証。

## 実機検証の範囲
- 390×844・320×700の隔離Chromeにおける名前入力枠の位置、下側黒帯への収まり、キーボードの自動フォーカス回避は検証済み。
- Safari実機の日本語入力中のレイアウトは、引き続き公開後に確認する。
