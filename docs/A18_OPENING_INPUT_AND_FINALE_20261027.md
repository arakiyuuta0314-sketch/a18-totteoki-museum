## 修正箇所
- `layout-test/opening-v1.js`
  - 名前入力欄の即時 `.focus()` を廃止。入力フォーム到達時に自動でキーボードを開かない。プレイヤーが入力欄を**自分でタップ**して入力する。
  - `finish()`：①セピア画像枠だけ白くなる→②画像の実表示座標から全画面へ白を拡大→③全画面が白い間に既存ゲーム側の執事イベントを開始→④オープニングレイヤー全体の不透明度をゆっくり下げてカラーの館内を見せる。
  - 元の保存処理・呼称・美術館命名イベントは変更しない。
- `layout-test/opening-v1.css`：全画面マスクのクリップ拡大と、ゲームへの穏やかな透過フェード。
- `layout-test/index.html`：新CSS/JSのキャッシュ識別子のみ更新。
- 画像4枚・タイトル画像・台詞・途中の場面転換は変更なし。
