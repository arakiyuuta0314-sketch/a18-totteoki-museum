## 操作・共有方法
1. iPhone/PCで公開された配置エディターを開き、カウンター・仕切り壁・写真それぞれをドラッグ、ハンドル/スライダーで縮尺変更。背景は固定。
2. **上部の「配置リンクをコピー」**を押し、ChatGPTの会話にリンクをそのまま貼る。座標（左・上・幅・高さ・傾き・表示/非表示）をすべてリンクの `layout` パラメータに含める。スクショだけに頼らない。
3. クリップボードが拒否された場合は、下部のテキスト欄を長押しして手動コピーする。
4. 端末内の自動保存は `localStorage["a18-placement-editor-v2"]`（旧SVG仮素材版とは独立）。URL `layout=` は旧版の座標も読み込める。ゲーム本体のIndexedDBには触れない。
5. `?layout=...` を送信するのは**配置の意思表示のみ**。このリンクは公に開けるため、ユーザー個人の作品写真を埋め込まない。ローカル画像差し替えは共有リンクに含めず、その端末限り。
