# A18 Lv.1 エントランス配置エディター（独立プレビュー）

## 目的
家具・写真の配置座標をChatGPTが勝手に推測する失敗を解消する。ユーザーがスマホ/PCの実公開ゲームの録画でなく**ブラウザ検証実画面の静止スクリーンショット**上で、各独立オブジェクトをタッチドラッグして決められる。

## 仕様
- 背景 `reference-game.png` は 2026-10-27 に隔離Chromeで実際に公開ゲームのチュートリアルを完了し、テスト写真で撮影した 780×1688 のスクリーンショット。背景の描き直しを行わない。実利用者の保存データは使わない。
- `counter.svg` は**移動確認用の仮カウンター素材**、`wall.svg` は写真・台紙・額縁を含まない仮の仕切り壁、`picture.svg` は位置合わせ用の仮写真。**どれも完成美術素材と見なさない**。
- 「カウンター」「右の仕切り壁」「作品の表示サイズ」はそれぞれドラッグ、ハンドルリサイズ、X/Y/W/H 数値指定、スライダー、傾き変更、表示切替可能。
- **仕切り壁をドラッグすると作品も一緒に移動するが、仕切り壁を拡大縮小しても作品のW/Hは変わらない。**作品を単独で動かして大きさを合わせられる。
- 自動保存は専用 `localStorage` キー `a18-placement-editor-v1` のみ。既存ゲームのIndexedDBには触れない。共有リンク `?layout={URL encode JSON}` はすべての独立座標を復元できる。
- 画像ファイルの差し替えはこの画面の一時表示のみ。共有リンクは位置/サイズ/傾き/表示状態を共有するが、ユーザーが読み込んだローカル画像のバイナリを含まない。
- 配置が確定したら共有リンクをユーザーがチャットに貼る。受け取った座標を完成素材・当たり判定・前後レイヤー・写真投影窓へ反映するのは**別の実装工程**。

## 検証・制約
- 監修採用済みの「左へ48寄せ」を起点とする（壁は調整対象）。
- ブラウザQA `entrance-lv1-layout-draft-20261027/qa_placement_editor.py` でデスクトップ/スマホ相当各15項目、合計30/30 PASS。ソース画像の取得、タッチ対応pointerイベント、独立サイズ変更、共有リンク復元、保存、HTTP/JS エラー有無までテスト。
- 本ツールにユーザー登録フォーム・作品保存・移動・当たり判定などゲームの処理はなく、単独のプレビュー。
- ゲームソース・背景・奥の額縁2枚・中央扉・プレイヤー資産は変更しない。
