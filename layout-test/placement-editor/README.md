## 操作・共有
- 位置・角度・サイズはドラッグ・ハンドル・数値入力で編集できる。
- 「配置リンクをコピー」で全データを `?layout=...` にエンコードしてチャットへ貼るだけ。スクリーンショットを基に座標推測しない。
- 保存はこのプレビューツール専用 `localStorage['a18-placement-editor-v3']`。旧版v2の配置は消さない。既存URLの `layout` クエリは、旧座標でも読み込めるので旧リンクから開くと元の大きさになる点に注意。
- 依頼がない限りカウンターと右壁の本ゲーム統合、issue/mainへの全レイアウト試作一式のマージはしない。
