# A18｜右手前の壁面基準・展示額縁 v07（美術完成候補）
2026-10-26 / 最終美術承認待ち

## 今回の原因と変更
v06では額縁・台紙・写真の単一射影変換には成功したが、目標の外周4点を古い金額縁から流用したため、背景壁面のパースと不一致になっていた。
v07では43番の「entrance_bare_three_frame_backing.png」の右手前にある緑色展示壁を正とし、壁面の上・下の建築線から四隅を推定して、その壁面内へ額縁を配置する。

### 壁面の基準点（546×483・原画由来推定値）
wall_plane Quad TL(405,157), TR(509,197), BR(501,369), BL(405,294)。
これらは**画像からの計測・推定値**。元の3Dモデルから得た確定座標ではない。
正面wall座標に対し表示領域を UV (.15,.13),(.94,.13),(.94,.88),(.15,.88) に配置。壁面投影Hでこの4点を画面座標へ変換。
得られた額縁外周はおおよそ TL(417.31,181.20), TR(500.01,217.51), BR(494.57,344.38), BL(416.74,287.08)。

## 再利用する設計
- 壁面四隅と正規化された表示位置だけをエリア別に変更する。
- 正面素材（44番の木製、43番の金額縁・写真窓・台紙・写真サンプル）自体は共通。
- 額縁の表示先四隅は壁面への射影変換から自動算出。
- その四隅に対する単一のHを使って、木製・金色・写真・台紙・マスクを一括変形。
- 写真窓の内周は外周からHで自動計算し、独立した手入力座標を禁止する。
- 将来の反対角度は壁面四隅を別に与えるだけで処理は再利用できる。現在の逆角度画像は技術検証のみ。
