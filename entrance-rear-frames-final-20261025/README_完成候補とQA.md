4. 額縁の写真窓Alpha=0、額縁の透過窓が写真を暗くしない。
5. 正式キャラクター2種は原本PNGとバイト一致。再生成・改変なし。
6. 390×844の実Chrome・デバイス倍率2でページを起動。画像HTTP成功、
   左右サイズ、写真切替、復元を操作。ブラウザエラー0。

8. このバージョンは完成候補素材。ユーザーの美術最終確認前・ゲーム実装前。
